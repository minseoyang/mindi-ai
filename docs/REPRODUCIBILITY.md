# 실험 재현 메모

이 저장소는 개발 당시 실험 코드의 보관본입니다. 코드 정리 과정에서는 API 키를 환경 변수로 바꾸고 개인 컴퓨터의 일부 절대 경로를 상대 경로로 바꿨습니다. 모델 구조·학습 목표·점수 계산 규칙은 원본을 유지합니다.

## 확인한 사항

- Python 소스의 문법 검사 통과
- 소스에 기록된 OpenAI API 키를 `OPENAI_API_KEY` 환경 변수로 교체
- 원본 데이터, 사용자 정보, 대화 로그 및 모델 가중치 제외

모델 다운로드·가중치 로딩·추론·외부 API 요청은 이번 정리 과정에서 실행하지 않았습니다.

## 실행 환경

모듈에 따라 PyTorch, torchvision, torchaudio, Transformers, datasets, librosa, praat-parselmouth, pandas, NumPy, scikit-learn, Pillow, matplotlib, pydub, soundfile, joblib, OpenAI SDK, watchdog을 사용합니다. 파일 변환 함수는 FFmpeg 실행 파일을 호출합니다.

원본 환경 목록과 현재 코드에서 사용하는 API가 섞여 있어, 전체 실행을 보장하는 의존성 버전 목록은 아직 정리하지 않았습니다.

`OPENAI_API_KEY`는 실행하는 환경에 직접 설정해야 합니다. `.env.example`은 변수 이름 안내용이며 코드가 자동으로 읽지 않습니다. 실제 음성·대화를 외부 API에 보내는 실험은 데이터 이용 조건에 맞춰 진행해야 합니다.

## 가중치와 입력 파일

- 영어 음향 모델: `acoustic_model/vit.pth`, `acoustic_model/lgbm.pkl`
- 영어 텍스트 모델: `language_model/final_BERT.pt`
- 한국어 음향 확장: `ko_acoustic_model/vit_model_ver2.pth`, `ko_acoustic_model/lgbm_model_ver2.pt`
- 한국어 텍스트 확장: `ko_language_model/final_KoBERT.pt`
- 분석 입력: 각 모델 결합 파일이 참조하는 `wav/` 또는 `ko_wav/`의 응답 음성
- 사용자 정보: 모델 결합 실험의 연령·학력 입력 파일
- 케어·리포트 입력: 해당 모듈에서 참조하는 음성 및 날짜별 대화 로그

이 파일들은 공개본에 포함하지 않습니다. 재현 전에 모델의 출처, 레이블 방향, 입력 구성 및 공개·이용 가능 범위를 확인해야 합니다.

## 현재 코드에서 정리할 사항

1. **OpenAI SDK 호출 방식**: 분석·리포트 일부는 새 클라이언트 방식, 케어 일부는 이전 `ChatCompletion` 방식을 사용합니다. 실행 환경에 맞춰 통일해야 합니다.
2. **KoBERT 반환값 연결**: `KoBERT_final`은 정수를 반환하지만 호출부 일부는 `bert_score["score"]`처럼 접근합니다. 한국어 전체 실행 전에 반환값 규약을 맞춰야 합니다.
3. **영어 문항 평가 제어 흐름**: `language_model/main.py`의 최종 반환문이 집행기능 반복문 안에 있습니다. 설계한 문항 합산 범위와 비교해 정비해야 합니다.
4. **실행 진입점**: 일부 모듈은 import 시 음성 전사나 예시 코드를 실행합니다. 독립적으로 재사용하려면 진입점 분리가 필요합니다.
5. **케어 모듈 연결**: 반복 대화의 입력 파일 선택, 메시지 형식, 전체 로그 누적, 키워드 추출 연결을 점검해야 합니다.
6. **모델 버전 구분**: 한국어 `lgbm_model.py`는 신경망 분류기입니다. 파일명, 문서의 모델명, 학습·추론 가중치의 대응을 정리해야 합니다.
7. **평가 재현**: 데이터 분리 단위, 동일 화자의 학습·평가 분리 여부, 평가 데이터셋 명칭과 지표를 다시 확인한 뒤 성능 수치를 공개합니다.

이 메모는 원본 코드의 재현 상태를 설명합니다. 아직 전체 실행을 검증한 배포용 패키지는 아닙니다.
